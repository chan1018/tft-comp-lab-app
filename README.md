# TFT 構成ラボ（公開版）

Teamfight Tactics Set 18「神秘の森」の**理論値ツール**。個人用の非公式ツールです。

**→ https://chan1018.github.io/tft-comp-lab-app/**

ブラウザだけで動きます（サーバーもビルドも不要）。スマホでも開けます。

## 何をするツールか

**パッチが来た直後に、まだ誰も使っていない強い構成を見つける**ためのものです。

実測（op.gg 等の平均順位）は集計が終わるまで前のパッチのままなので、実測だけを見ていると
必ず出遅れます。一方パッチノートは公開と同時に手に入ります。そこで:

- **パッチの追い風** — 今回のパッチでその構成の駒がどれだけ上方修正されたか
- **組みやすさ** — 合計コスト・キャリーのコスト・プール枚数・5コストの数
- **構成の派生** — 引きが悪くても組み替えが効くか（1体入れ替えの通り数）
- **実際にかかるゴールド** — 2★にするには3枚要るので、コスト合計とは別物

の4つを並べて、最後は人が判断する形にしてあります。

## 出している数字と、出していない数字

**出す**
- 8秒の戦闘で出る合計ダメージ（理論値）
- 実効耐久・軽減率・回復とシールド込みの耐久
- 28ヘクスの初期配置（相手の盤面を手入力して計算）
- リロールの確率（Riot のマップデータ由来の実値）
- 後衛に届くユニットの印 — **「跳ぶか」ではなく「誰を狙うか」で判定**しています

**出さない**
- 勝率・順位。理論ダメージは順位をほぼ説明しませんでした（コストに上乗せする説明力 R² +0.000）。
  理論値が答えるのは「何秒後に何ダメージ出るか」であって「何位になるか」ではありません
- オーグメントの強さ順。組み合わせ別の実測がどのデータ源にも存在しないため、
  出せるのは「矛盾しない次の一手」まで

**未検証の前提は画面に出しています。** 隠すのが一番危ないので。

## この版について

これは**公開版**で、実測の集計値（平均順位・試合数・使用率）を落としてあります。
ツールの本体（パッチ解析・理論値・構成・配置・リロール確率）はすべて入っています。

ユニットの画像は含まれていません（Riot の資産なので再配布しません）。
画像が無くても画面は成立します — 頭文字とコスト色の丸で表示されます。

## データの出どころ

- **Riot**（Community Dragon / Data Dragon）— ユニット性能・トレイト・アイテム・
  オーグメント・ショップ確率・プール枚数・経済
- **スキル係数** — Riot が Set 18 の係数を配信していないため、二次データで補っています（充足率 96%）
